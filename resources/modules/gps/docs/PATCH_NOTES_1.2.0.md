# EnoGPS Patch Notes (for players)

## Update 1.2.0

This update includes everything added after version `1.5.0`.

- New **Options** menu in `/gps` main GUI.
- Options now include:
  - `Show Distance` toggle
  - `Show High/Low` toggle
  - `Show Target Name` toggle
  - `Compact HUD` toggle
- Improved menu navigation:
  - Added **Back** button to all non-main GPS menus.
- Updated target selection layout:
  - **Points of Interest** moved to slot `30`
  - **Block target** moved to slot `32`
- Main menu cleanup:
  - **Options** button moved to slot `31`
  - **Stop Navigation** button shown when route is active
- Better startup/version clarity in console (shows actual loaded plugin version and jar file).
- Docs/manuals are now bundled directly inside the plugin jar under `docs/`.
- Added and expanded integration support docs (BetonQuest, GPS API, staff/admin usage, legal notes).
